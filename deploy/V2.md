# Aichemy V2 — pengoperasian dan pembaruan

## Perluasan pilihan Racik — 23 Oktober 2026

Katalog 3 kini mempunyai 2.496 entri pilihan aktif lintas 18 jasa (tidak menghitung “Tanpa”; beberapa opsi dipakai di beberapa jasa, jadi ini bukan jumlah opsi unik). Jumlah gaya awal tetap 218. Perluasan berada di `server/expanded-options.ts`, bukan bundle frontend. Katalog 1/2 tidak menerima opsi baru secara diam-diam.

Ada 126 foto baru dari built-in imagegen di `design/expanded-options/originals`. `jobs.json` menyimpan prompt, referensi, jasa, field, nilai, dan seri pembanding; `reviews.json` mencatat tinjauan; `manifest.json` menghubungkan sumber dengan WebP 1000 px dan thumbnail 450 px. Jalankan `npx tsx scripts/prepare-expanded-options.ts` untuk menyiapkan brief generasi, buat foto melalui imagegen bawaan, lalu `node scripts/prepare-expanded-assets.mjs`. Tinjau contact sheet sebelum menandai reviewed. Build menolak seluruh foto wajib yang hilang atau belum ditinjau. Jangan mengganti sumber generasi yang sudah dirilis; buat nama versi baru untuk perubahan berikutnya.

Pengaturan hewan yang baru (tambahan sekitar hewan, potongan, ketajaman latar) dimulai dari `__skip`. Tidak ada migrasi database. Opsi lama tetap menggunakan ID yang sama; contoh sudut aksesori diperbaiki agar bukan botol, termasuk instruksi detail sambungan yang sebelumnya memakai detail tutup botol. Prompt manual tetap terpisah dan aman.

Galeri menampilkan 24 kartu per halaman tambahan, mendahulukan pilihan aktif, serta mendukung pencarian beberapa kata dan filter kelompok. Warna, rasio, bentuk, tipografi, dan panduan bingkai memakai visual deterministik berlabel; foto cahaya/lensa bukan simulasi optik terukur. Seluruh katalog gambar tidak dimuat saat builder dibuka.

Bagian di bawah merupakan dokumentasi/histori implementasi sebelumnya.

V2 mempertahankan akun, PostgreSQL, pembayaran, entitlement lifetime, dan URL recipe lama. Tidak ada migrasi tabel baru: data V2 menggunakan JSONB pustaka yang sudah ada. Harga tetap ditentukan server: 149000 IDR.

## Menjalankan lokal

Gunakan konfigurasi pada [README](README.md). Jalankan `npm run dev:server` dan `npm run dev` pada terminal terpisah. Database dan SMTP/Mailpit harus tersedia. `npm run typecheck`, `npm test`, `node scripts/check-recipe-prompts.mjs`, `npm run validate:v2`, `npm run build`, dan `npm run test:browser` adalah pemeriksaan rilis.

Playwright memerlukan database lokal `aichemy_dev`, Mailpit port 8025, frontend 5173, serta backend 3001. Test membuat pengguna sintetis sendiri, memverifikasi email melalui Mailpit, memberi entitlement sandbox untuk fixture, dan membersihkan pengguna fixture. Jangan menjalankan test terhadap database produksi.

## Kontrak API V2

- `POST /api/studios/:recipeId/preview`: wajib sesi dan entitlement aktif. Kirim `{ engineVersion: 2, state: { catalogVersion: 2, serviceId, setId, referenceMode, brief, selections } }`. Respons berisi `state` efektif, `effectiveChoices`, `fields`, `document.blocks`, `document.text`, `referenceGuide`, dan `issues` per kolom.
- Tanpa `engineVersion: 2`, endpoint tetap memakai mesin V1 untuk kompatibilitas.
- `POST /api/demo/preview`: publik, maksimal 40 permintaan/menit/IP. Hanya `professional`, `formal`, `product`; hanya daftar terbatas latar, cahaya, dan karakter lensa. Brief, set, dan mode referensi permintaan tidak membuka katalog premium. Compiler sama dengan anggota; pilihan dasar lain dapat dilihat pada ringkasan efektif.
- `GET /api/viral-prompts` dan `GET /api/viral-prompts/:id`: wajib sesi + entitlement. Daftar tidak menyertakan teks prompt; detail hanya mengirim konten terbit yang tersedia pada tanggalnya. Tidak ada CRUD admin baru.
- `PUT /api/library/:id`: kepemilikan tetap diperiksa. Data draft/preset V2 mencantumkan `schemaVersion: 2`, `engineVersion: 2`, `state`, serta `manual`. Draft juga menyimpan `clientModifiedAt`; autosave dengan waktu lebih lama tidak boleh menimpa versi baru.

Jangan mengimpor `server/engine-v2.ts`, `server/viral.ts`, atau JSON prompt lengkap ke file frontend. Metadata teaser publik tidak mengandung prompt lengkap. Jangan menambahkan konten draft ke metadata/aset publik.

## Menambah Prompt Viral melalui file

Koleksi aktif memuat 18 prompt **fotografi**. Empat entri mengacu pada laporan tren/teknik; 14 lainnya berlabel Kreasi Aichemy. Catatan sumber, batas interpretasi, dan pipeline contoh foto ada di `design/v2/viral-photography-research.md`. Efek ilustrasi/figur lama disimpan sebagai arsip dan tidak dilayani API.

1. Siapkan ID unik, prompt final tanpa placeholder wajib, panduan referensi, serta contoh awal/hasil dari sumber sintetis/orisinal yang sama. Dapatkan izin bila memakai materi pihak lain.
2. Tambahkan entri privat pada `server/content/viral-prompts.json`. Contoh format:

   ```json
   {
     "id": "efek-baru",
     "status": "draft",
     "publishedAt": "2026-10-22",
     "prompt": "Write the complete, ready-to-copy English instructions here. Include reference roles, preservation requirements, visual direction, and constraints. Use an original concept with no fabricated product claims or endorsements. The complete published prompt must contain at least 200 characters."
   }
   ```

3. Ketika benar-benar akan terbit, ubah status menjadi `published`, isi tanggal publikasi aktual dalam UTC, lalu tambahkan metadata pada `shared/viral-photography.ts` (diekspor ulang oleh `shared/v2-catalog.ts`). Gunakan `medium: "photography"` serta `curation: "aichemy"` atau `"research"`. Entri riset wajib memuat judul, URL HTTPS, tanggal tinjauan, jenis acuan, serta penjelasan sumber. Tanggal rilis bukan bukti popularitas.
4. Simpan sumber di `design/v2/`, aset WebP besar dan thumbnail pada namespace versi baru di `/public/assets/v2/viral/`, serta catatan prompt, referensi, dan tinjauan pada `design/v2/viral-assets.json`. Koleksi fotografi terkini memakai subfolder `photography-v2`. Nama: `ID-before.webp`, `ID-after.webp`, dan versi `-small.webp`.
5. Periksa identitas/objek sebelum memberi `reviewed: true`. Jangan menandai selesai hanya karena berkas ada. Label default adalah **Kurasi**. Klaim sedang tren memerlukan sumber dan tanggal pengamatan, bukan sekadar nama koleksi “Prompt Viral”.
6. Perbarui angka koleksi di landing dan test jika menambah jumlah efek. Jalankan seluruh pemeriksaan rilis, lalu deploy ulang. Tidak ada pemantauan otomatis atau janji pembaruan harian.

## Mengubah set atau pilihan visual

Opsi baru perlu tiga hal: label/pengaruh yang mudah dipahami, instruksi semantik yang masuk ke blok yang benar, dan aset pembanding yang relevan. Gambar lensa memakai subjek/adegan/cahaya konsisten, dengan jarak kamera yang dijelaskan. Bukan simulasi optik terukur. Jangan mengarang perbedaan kamera hanya berdasarkan merek bodi.

Katalog visual V2 memakai alur **kartu pilihan aktif → Ubah → galeri → pilih**. Galeri mencari nama, kelompok, dan kata bantu; pilihan aktif diberi status **Dipakai**. Tombol perbesar terpisah dari tombol pilih. Menutup dialog tanpa memilih tidak mengubah state. Desktop memakai dialog besar, mobile dialog layar penuh. Semua perubahan menyimpan pilihan dan meminta pratinjau prompt baru tanpa menimpa suntingan manual.

Setiap jasa mempunyai 16 gaya awal, total 176. Pilihan fotografis terkini berada di `option-assets-v3.json`; contoh sampul set berada di `style-assets-v3.json`, terpisah dari 33 studi kasus sebelum–sesudah. Atlas sumber, prompt generasi, urutan nama, dan batas crop tersimpan di `option-atlas-jobs-v3.json`. Untuk grid yang panelnya tidak rata, masukkan `columnBounds` dan `rowBounds` eksplisit; jangan mengandalkan pembagian sama besar jika garis tile terlihat pada hasil. Jalankan `node scripts/split-v2-atlas.mjs design/v2/option-atlas-jobs-v3.json`, periksa crop besar dan thumbnail, lalu pastikan `reviewed`/`reviewNotes` benar sebelum validasi.

Pilihan yang sudah memiliki katalog visual besar mencakup: latar Profesional 24, pakaian/pose Profesional 16, Pas Foto 16 warna latar, Prewedding 16 pose/busana/dekorasi/buket dan 24 tempat/latar, cahaya foto kreatif 12, serta 24 latar Produk dan Makanan. Semua gambar berlabel ilustrasi; seri prewedding memakai pasangan yang sama, sedangkan latar produk dan makanan mempertahankan objek utama.

Manifest opsi dasar dan makanan terpisah (`option-assets.json` dan `food-option-assets.json`) tetapi diperiksa sebagai satu katalog lama. Opsi baru dan sampul set V3 punya manifest tersendiri. Gunakan nama versi baru ketika mengganti aset yang sudah dirilis; jangan membuat cache pelanggan diam-diam menunjuk gambar dengan arti baru. Gambar berbagi terkini ada di `social-v3.png`, dibangun ulang secara deterministik melalui `node scripts/prepare-v2-social.mjs`. Sampul gaya di area anggota harus memakai helper `setImage`, sedangkan galeri sebelum/sesudah memakai `caseImage`.

Warna latar dirender sebagai swatch CSS presisi di belakang subjek transparan yang sama. Rasio, layout, palet, serta tipografi menggunakan preview deterministik. Opsi fotografis memakai aset generatif tersimpan. Foto-foto ini ilustrasi pengaruh, bukan render live dari kombinasi pengguna.

Set baru harus memiliki metadata studi kasus dan aset awal/hasil. Tambahkan aturan ketergantungan dengan alasan yang terlihat; jangan menyembunyikan perubahan gaya di compiler. `npm run validate:v2` menggagalkan build bila aset wajib hilang, pemetaan salah, sumber hilang, atau tinjauan belum selesai. Paths sumber absolut dari mesin pengerjaan direbasiskan ke direktori proyek oleh validator agar checkout di VPS tetap portabel.

## Data lama dan keamanan suntingan

Draft V1 tetap dibuka menggunakan mesin V1. Tombol **Buat salinan V2** membuat ID baru, menyimpan seluruh data sumber pada `legacySource`, menyalin brief yang dikenali serta manual, dan tidak menimpa sumber. Parameter lama tidak dipaksakan menjadi padanan baru. Preset V1 hanya memetakan opsi kompatibel dan menjelaskan yang tidak tersedia.

Pergantian set/preset/Acak Gaya mempertahankan brief, merek, teks klien, dan suntingan manual. Mode otomatis tetap diperbarui terpisah. Kembali ke otomatis memerlukan konfirmasi dan dapat di-undo dalam sesi.

Draft tersimpan pada akun. Saat belum terkonfirmasi server, browser menyimpan salinan pemulihan sementara yang diberi namespace akun + ID draft; salinan dibersihkan setelah autosave terkonfirmasi. Ini bukan pemberian akses melalui localStorage. Semua pembacaan/simpan/preview tetap melewati pemeriksaan sesi dan entitlement server.

## Batas produksi

V2 tidak menambahkan generator gambar, penerjemah berbayar, CRM, kursus, atau pengelolaan pesanan klien. Hasil gambar, lisensi generator, biaya alat, dan pemeriksaan kualitas tetap tanggung jawab pengguna. Landing menampilkan tiga contoh omzet dari `INCOME_EXAMPLES`, tanpa kalkulator. Harga jasa di situ bersifat ilustratif; bukan patokan pasar, prediksi, atau laba bersih. Jumlah jasa/gaya/prompt berasal dari `PRODUCT_COUNTS` agar tidak berbeda dari katalog.

Domain/HTTPS, identitas penjual, dukungan, SMTP produksi, secret, kredensial Midtrans, serta uji sandbox merchant sungguhan tetap harus diselesaikan sebelum penjualan dibuka. Jangan menganggap gateway tiruan pada test sebagai bukti transaksi merchant berhasil.

# Katalog 3: perluasan jasa dan pose karakter

Katalog terbaru adalah versi **3**, sementara schema/engine draft tetap versi **2**. Sebelas jasa lama mempertahankan 16 gaya masing-masing; tujuh jasa baru punya enam gaya masing-masing: total 18 jasa dan 218 gaya. Definisi publik berada di `shared/services-v3.ts`; instruksi premium hanya di `server/options-v3.ts` dan `server/engine-v2.ts`.

- Simpan `catalogVersion` pada state. Draft tanpa versi tetap katalog 1; katalog 2 tidak dinaikkan otomatis. Tombol duplikasi membuat ID draft baru dan mempertahankan sumber/manual.
- `__skip` adalah opt-out yang eksplisit. Jangan mengubahnya menjadi default, string kosong, atau instruksi menghapus pakaian/subjek. API tetap memvalidasi semua data.
- Setiap gambar contoh bisa dipakai untuk menjelaskan pilihan, bukan render live. Jangan mengubah 42 sampul jasa baru menjadi pasangan sebelum/sesudah dengan foto lain yang tidak konsisten.
- Jalankan `node scripts/prepare-pose-bank.mjs` untuk menyiapkan brief sembilan pose. Generasi dilakukan melalui built-in imagegen, satu panggilan per foto. Jangan mengganti sumber identitas dengan foto orang lain atau memakai pose selfie yang sama untuk semua aset.
- `npx tsx scripts/prepare-diverse-portfolio.ts` menyiapkan 28 brief dengan referensi pose berbeda. Sumber terpilih disimpan di `design/v3/originals-v2/`; sumber sebelumnya tetap di `originals/`. Perubahan file jobs tidak otomatis menghasilkan gambar.
- `node scripts/prepare-expansion-assets.mjs` dan `node scripts/prepare-pose-assets.mjs` membuat WebP, thumbnail, manifest, dan contact sheet dari sumber yang benar-benar ada. Tinjau visual dulu, lalu isi `visual-reviews.json` / `pose-bank/reviews.json`. Aset versi kedua memakai nama `-v2`; `portfolioImage` dan `setImage` memilih path yang sesuai. Jangan mengesahkan manifest tanpa melihat hasil.
- Foto sumber pribadi/sintetis hanya untuk generasi aset proyek. Aichemy tidak menambahkan unggahan atau penyimpanan foto klien. Prompt pengguna tetap dibuat oleh engine aturan, tanpa biaya API AI per prompt.
- Harga tetap Rp149.000 lifetime; API premium, ownership, autentikasi, checkout, dan lisensi tidak diperlonggar. Jalankan `npm run typecheck`, `npm test`, `npm run build`, dan `npm run test:browser` sebelum rilis.

Riset dan self-review sepuluh putaran: `design/v3/research-and-review.json`. Hasil verifikasi terbaru ada di bagian paling atas `VERIFICATION-V2.md`; uraian V2 terdahulu di bawah dipertahankan sebagai konteks historis.
