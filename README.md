# Aichemy

Prompt builder visual untuk kreator Indonesia. Frontend React/Vite, backend Fastify/Better Auth, PostgreSQL, dan pembayaran Midtrans sandbox. Harga produk Rp149.000 sekali bayar untuk akses lifetime satu akun.

Lihat [panduan lokal dan VPS](deploy/README.md) untuk konfigurasi, migrasi, email, pengujian, backup, serta aktivasi merchant. Perubahan web baru berada pada `web/`; mesin recipe yang ada tetap digunakan di server. Draft, preset, favorit, dan studio pribadi tersimpan per akun.

Logo yang dipilih pengguna dan aset asli berada pada `design/originals/`. Aset web teroptimasi berada pada `public/assets/`. Catatan generasi tersedia pada `design/generated-assets.json`.

Lihat [hasil pengujian dan batas kesiapan produksi](deploy/VERIFICATION.md) sebelum membuka penjualan.

Aichemy menyusun teks prompt; pengguna membuat gambar melalui aplikasi AI pilihan mereka. Tidak ada generator gambar atau kunci model AI yang dibutuhkan oleh platform.
